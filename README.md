# Smart Irrigation System Using IoT

## Project Overview
This project is a Dual Layer Soil Moisture Based Smart Irrigation System using IoT. It automatically monitors soil moisture levels and controls irrigation based on soil conditions. This system helps save water, reduces manual effort, and improves farming efficiency.

## Objectives
- Monitor soil moisture automatically
- Reduce water wastage
- Automate irrigation
- Improve crop productivity

## Components Used
- Arduino Uno
- Soil Moisture Sensor
- ESP8266 Wi-Fi Module
- Relay Module
- Water Pump
- Jumper Wires
- Breadboard

## Software Used
- Tinkercad
- Arduino IDE

## Features
- Automatic irrigation
- Water-saving system
- IoT-based monitoring
- Easy to use
- Low-cost solution

## Working
The soil moisture sensor continuously checks the moisture level of the soil. When the soil becomes dry, the Arduino turns on the water pump through the relay module. When the required moisture level is reached, the pump automatically turns off.
